Story

ABAP 개발자가 된 이유

안전관리자로 재직하던 중, ERP 개발 설명회에 참석한 적이 있습니다. 그 자리에서 기업의 자원 관리와 업무 과정이 전산 시스템으로 운영되는 모습을 보며 ERP와 같은 통합 관리 시스템에 관심을 가지게 되었습니다. 특히 재고가 자동으로 관리되고, 수요 예측에서 판매까지 이어지는 구조를 접하며 "이런 시스템을 직접 개발해 기업의 효율을 높이고 싶다"는 목표가 생겼습니다.

이후 정보처리기사 필기시험에 합격하고 현재 실기를 준비하며 JavaScript, SQL(SQLite·MySQL·PostgreSQL) 등을 학습했습니다. SAP CODE 아카데미는 단순히 코딩을 배우는 과정이 아니라, SAP와 ABAP을 기반으로 ERP 시스템을 설계·구현하는 실무 역량을 체계적으로 쌓을 수 있다는 점에서 선택했습니다.

학습 과정에서는 단순한 기능 구현보다 구조적인 이해를 우선시했습니다. ALV 구현 방식, 도메인 텍스트 매핑, 프로그램 구조 설계 등 다양한 기술을 비교·분석하며 동작 원리와 구조를 끝까지 추적했고, 반복적으로 발생하는 로직은 공통 함수로 정리해 팀 전체의 시행착오를 줄이는 방식으로 협업했습니다.

  • ABAP Spool → PDF 직접 다운로드 (개별 / 전체)
  • 동적 TOP-OF-PAGE — 총 전표수, 금액, 기간 3×3 카드 자동 생성
* 역분개 로직 — SHKZG 자동 반전 + 양방향 STBLG 연결 LOOP AT lt_items_orig INTO ls_item. ls_item-shkzg = COND #( WHEN ls_item-shkzg = 'S' THEN 'H' ELSE 'S' ). APPEND ls_item TO lt_items_rev. ENDLOOP.
