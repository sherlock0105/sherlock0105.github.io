Story

ABAP 개발자가 된 이유

안전관리자로 재직하던 중, ERP 개발 설명회에 참석한 적이 있습니다. 그 자리에서 기업의 자원 관리와 업무 과정이 전산 시스템으로 운영되는 모습을 보며 ERP와 같은 통합 관리 시스템에 관심을 가지게 되었습니다. 특히 재고가 자동으로 관리되고, 수요 예측에서 판매까지 이어지는 구조를 접하며 "이런 시스템을 직접 개발해 기업의 효율을 높이고 싶다"는 목표가 생겼습니다.

이후 정보처리기사 필기시험에 합격하고 현재 실기를 준비하며 JavaScript, SQL(SQLite·MySQL·PostgreSQL) 등을 학습했습니다. SAP CODE 아카데미는 단순히 코딩을 배우는 과정이 아니라, SAP와 ABAP을 기반으로 ERP 시스템을 설계·구현하는 실무 역량을 체계적으로 쌓을 수 있다는 점에서 선택했습니다.

학습 과정에서는 단순한 기능 구현보다 구조적인 이해를 우선시했습니다. ALV 구현 방식, 도메인 텍스트 매핑, 프로그램 구조 설계 등 다양한 기술을 비교·분석하며 동작 원리와 구조를 끝까지 추적했고, 반복적으로 발생하는 로직은 공통 함수로 정리해 팀 전체의 시행착오를 줄였습니다.

프로젝트가 해결한 과제

화장품 제조·판매 기업 Master Pack ERP 구축 프로젝트가 풀어낸 비즈니스 과제입니다.

01
다국적 거래에서 환율 관리의 복잡성
AS-IS수출 비중 급증으로 달러·엔화 등 다양한 통화 거래가 발생하나 실시간 환율 반영 체계가 부족
TO-BEBatch Job으로 매일 환율을 가져와 환율 마스터 테이블에 저장. 각 모듈에서 전표 생성 시 공용 Class Method 사용, 내부 Function Module에서 전기일 기준 환율 자동 계산·세팅. 전표 헤더·아이템에 환율 이력 저장으로 시점별 추적
AS-IS매출 처리와 대금 관리 시 환율 적용 시점이 달라 회계 오류 발생
TO-BE전표별 전기일 환율 + 반제일 환율 이력 저장 → 시점별 추적 가능 / 수동 반제에서 해결
AS-IS월말 결산 시 환율 변동에 따른 평가 손익 산출이 어려워 정확한 현금 흐름 파악에 한계
TO-BE월말 외화 채권·채무 일괄 재평가 배치 + 환평가 손익 리포트. 통화별 미결잔액 + KRW 환산액 TOP OF PAGE 표시
02
제품별 수익성 분석 체계 부족
AS-IS제품별로 발생하는 원재료비·생산비·물류비를 통합해 원가를 산정하기 어려움
TO-BE표준원가·실제원가 산정 후 월말에 원가 확인
AS-IS다양한 판매 채널별 수수료·프로모션 비용·물류비 등을 반영한 실질적 마진 분석 도구 부재
TO-BE수수료율·프로모션·물류비·관세를 판매유형(채널)에 매핑. 프로모션 비용 → BOM 등록(샘플)
03
채널·거래처별 판매정책 운영의 복잡성
AS-IS판매 채널과 거래처별 가격 및 할인 정책 관리가 복잡
TO-BE판매 채널·거래처·할인 정책 따로 테이블 만들어서 활용
AS-IS수기 관리에 따른 오주문 발생 및 대규모 수출에 필요한 각종 증빙 서류 작성에 과도한 시간 소요
TO-BE수출 서류 자동 생성 + 이메일 발송
AS-IS거래처별 리베이트 정산이 늦어지고 데이터 불일치가 발생하여 해외 파트너사와의 신뢰 관계 저하
TO-BE기간 내 목표 매출 달성 시 리베이트 자동 발생·정산·청구
04
원료 특성을 반영한 생산·재고 최적화 한계
AS-IS유통기한 기반 재고 운영 체계 미흡
TO-BE유통기한 필드 설정 → 원재료 FIFO, 완제품 FEFO 출고
AS-IS품질 관련 이슈 발생 시 생산 이력 추적 시스템 부재로 인한 원인 분석 및 대응 지연
TO-BE생산 LOT 단위 이력 추적으로 품질 이슈 원인 신속 파악
05
현장 업무·실시간 의사결정의 모바일 지원 한계
AS-IS영업팀 고객 방문 시 실시간 재고 확인 및 주문 처리 불가
TO-BE오프라인 매장(백화점)별 재고 실시간 조회 및 모바일 수주·긴급 오더 프로그램. 바코드/QR 스캔으로 재고 카운트
AS-IS경영진 출장 중 핵심 KPI 모니터링 및 승인 업무 처리 제약
TO-BE오더 승인·견적 승인·리베이트 정산 승인을 앱에서 처리. 모바일 임시전표 승인
