# 셜록의 작은 사건실

탐정 고양이가 돌아다니는 인터랙티브 사건실. 순수 HTML/CSS/JavaScript로 만든 정적 사이트입니다.

## 즐기기

- 반짝이는 장소 다섯 곳을 조사하면 사건의 결말을 볼 수 있습니다.
- 바닥을 누르면 탐정이 이동하고, 탐정을 누르면 산책이 멈춥니다.
- 음악은 직접 켤 수 있으며 브라우저 안에서 생성되므로 별도 음원 파일이 없습니다.
- 회중시계, 반복해서 누르는 게시판, 탐정의 모자에 작은 비밀이 있습니다.

로컬에서 `python -m http.server 8000` 실행 후 `http://localhost:8000`을 열면 됩니다. GitHub Pages는 저장소의 `main` 브랜치 루트에서 배포하면 됩니다.

방과 캐릭터 이미지는 이 프로젝트 전용으로 생성했습니다.
