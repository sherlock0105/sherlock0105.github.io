# 도현의 작은 방

픽셀 방의 물건을 눌러 할 일, 메모, 달력, 집중 타이머, 음악, 바로가기를 여는 반응형 개인 홈페이지입니다.

## 사용하기

- 공개 주소: `https://sherlock0105.github.io/pixel-room/`
- PC와 휴대폰에서 주소를 열어 사용합니다. 자주 띄우려면 브라우저 즐겨찾기나 시작 페이지에 등록하세요.
- 할 일, 메모, 일정과 링크는 현재 브라우저의 `localStorage`에 저장됩니다. 브라우저나 기기를 바꾸면 자동으로 동기화되지 않습니다.
- 음악은 처음 재생 버튼을 눌러야 시작합니다. 기본 음악은 이 사이트에서 직접 합성하는 짧은 오리지널 피아노 루프입니다. 보유한 음악 파일을 선택해 브라우저에서 재생할 수도 있습니다. 파일은 저장하거나 전송하지 않으므로 페이지를 새로 열면 다시 선택해야 합니다.
- Google Calendar 버튼은 사용자의 달력을 새 탭으로 엽니다. 이 사이트에 적은 일정과 Google Calendar는 서로 동기화되지 않습니다.

## 배포

정적 파일 `index.html`, `style.css`, `script.js`, `assets/room.webp`을 저장소의 `pixel-room/` 폴더에 둡니다. GitHub Pages가 저장소의 `main` 브랜치 루트에서 게시되면 위 주소로 접속할 수 있습니다.

별도 빌드나 API 키는 필요 없습니다. 이미지에는 기존 게임의 맵이나 캐릭터를 사용하지 않았습니다.
