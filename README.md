# 박도현 | SAP 포트폴리오

현장 업무를 이해하고, 구매·입고·회계 흐름을 시스템으로 연결하는 SAP 개발·설계 경험을 정리했습니다.

**[포트폴리오 보기](https://sherlock0105.github.io/)** · [CODE 프로젝트](https://sherlock0105.github.io/project.html) · [RAP 프로젝트](https://sherlock0105.github.io/rap.html)

## 경험과 방향

안전관리자로 3년간 현장 점검과 교육 업무를 맡았습니다. 이후 SAP CODE 아카데미에서 FI 결산 프로그램을 개발했고, RAP 심화과정에서는 구매부터 회계까지 이어지는 구조를 설계했습니다. 앞으로 재무·구매 업무 요구사항을 정리하고 구현 결과를 확인하는 SAP 컨설턴트로 성장하고자 합니다.

**사용 기술:** ABAP, ALV, SAP FI, CDS View, SAPUI5/Fiori, OData, RAP
