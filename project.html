— CHALLENGE

업무에서 무엇을 바꿨는가

교육 프로젝트에서 가정한 업무 상황입니다. 아래 세 가지는 제가 직접 개발하거나 통합 과정에서 확인한 부분입니다.

01
외화 거래와 월말 결산
직접 개발
AS-IS

환율 입력, 미결 전표의 평가손익 확인, 다음 달 환입이 따로 처리되면 결산 결과를 확인하기 어렵습니다.

TO-BE

환율 API 적재 → 전표 환율 반영 → 월말 평가 시뮬레이션 → 평가전표와 익월 환입전표 생성으로 흐름을 연결했습니다.

02
완제품 검수 결과 입력
직접 개발
AS-IS

검수 결과를 엑셀에서 옮길 때 형식 오류나 중복이 섞이면 저장 후에야 문제를 발견할 수 있습니다.

TO-BE

업로드 전 형식·중복을 검사하고 팝업 ALV에서 결과를 확인하도록 했습니다. 부분합격과 폐기 같은 예외도 구분했습니다.

03
청구 조건 변경과 FI 세금계정
통합 이슈
AS-IS

SD 청구 조건이 바뀐 뒤 FI 전표의 세금계정이 예상과 다르게 결정됐습니다.

TO-BE

전표의 세금코드, 청구 조건유형, 계정결정을 순서대로 비교해 원인을 찾고 변경 전 영향 검토 항목을 정리했습니다.

팀 전체가 다룬 다른 업무 과제 보기

아래는 프로젝트 전체 범위입니다. 제 직접 개발 범위와 구분해 두었습니다.

02
제품별 수익성 분석 체계 부족
AS-IS제품별로 발생하는 원재료비·생산비·물류비를 통합해 원가를 산정하기 어려움
TO-BEBOM 기반 원재료비, 생산 실적 기반 노무비, 배부 사이클을 통한 제조간접비를 생산오더 단위로 자동 집계하여 제품별 실제 제조원가 통합 산정. 표준원가 대비 실제원가 차이 분석 가능
AS-IS다양한 판매 채널별 수수료·프로모션 비용·물류비 등을 반영한 실질적 마진 분석 도구 부재
TO-BE납품·청구 데이터를 연계해 채널별 매출을 자동 집계하고, 실제 제조원가 기반 매출원가를 적용한 채널·거래처·품목 단위 마진 drill-down 분석 가능. 판매관리비 매출 비율 배부로 영업이익 수준까지의 실질 수익성 분석 구현
03
채널·거래처별 판매정책 운영의 복잡성
AS-IS판매 채널과 거래처별 가격 및 할인 정책 관리가 복잡
TO-BE채널·거래처·할인 정책을 독립 마스터 테이블로 분리하고 각각 관리 프로그램을 구현해 정책 변경 시 영향 범위 최소화 및 재사용성 확보
AS-IS수기 관리에 따른 오주문 발생 및 대규모 수출에 필요한 각종 증빙 서류 작성에 과도한 시간 소요
TO-BE청구서·수출신고필증·B/L을 자동 생성하고 거래처 이메일로 즉시 발송. 수작업 서류 작성 완전 제거
AS-IS거래처별 리베이트 정산이 늦어지고 데이터 불일치가 발생하여 해외 파트너사와의 신뢰 관계 저하
TO-BE목표 매출 달성 시 리베이트 발생·정산·청구를 자동화해 해외 파트너사와의 정산 오차 및 지연 제거
04
원료 특성을 반영한 생산·재고 최적화 한계
AS-IS유통기한 기반 재고 운영 체계 미흡
TO-BE유통기한 필드 적용으로 원재료 및 완제품 선입선출 진행. 유통기한 관리 배치잡으로 폐기 대상 및 할인 판매(잔여 3~6개월) 품목 자동 분류·알림
AS-IS품질 관련 이슈 발생 시 생산 이력 추적 시스템 부재로 인한 원인 분석 및 대응 지연
TO-BE배치 번호로 원료 입고→생산→출하 전 이력을 단일 조회로 추적. 품질 클레임 발생 시 원인 분석 및 신속 대응 가능
05
현장 업무·실시간 의사결정의 모바일 지원 한계
AS-IS영업팀 고객 방문 시 실시간 재고 확인 및 주문 처리 불가
TO-BEFiori 모바일로 실시간 재고 조회 + 고객 방문 현장에서 판매오더 즉시 생성. 사무실 복귀 없이 영업 마감 가능
AS-IS경영진 출장 중 핵심 KPI 모니터링 및 승인 업무 처리 제약
TO-BEFiori 기반 핵심 KPI 대시보드를 모바일에서 실시간 확인하고, 오더·전표 승인을 현장에서 즉시 처리 — ✓ 해결

핵심 기능 상세
  • 3-Tab 선택화면 (전체/AR/AP) — 탭 전환 시 해당 탭 조건만 검증 후 RETURN, 타 탭 필수값 오류 방지. 전표번호·전표유형·미결/반제 라디오 버튼 조건 포함
  • Split ALV — 상단 전표 목록 클릭 시 하단 전표 상세 동적 갱신. 차변/대변 컬럼 분리로 가독성 확보
  • 역분개 전표 하단 병렬 표시 — set_rev_item FORM으로 STBLG 연결된 역분개 전표를 원본 바로 아래 자동 배치
  • 마이너스 역분개 — SHKZG 유지 + dmbtr/wrbtr에 ×(-1) 적용. 전표유형 AB로 신규 채번 후 원본 STBLG 양방향 업데이트
  • 반제 전표 역분개 — DZ/KZ 유형 시 set_clear FORM으로 상대방 전표 augbl 초기화 후 역분개 진행
  • ABAP Spool → PDF 직접 다운로드 — 개별 전표 / 전체 전표 PDF 지원
  • 동적 TOP-OF-PAGE — CL_DD_DOCUMENT로 총 전표수·금액·미결·반제·역분개·조회기간 3×3 카드 자동 생성
  • 조건부 F4 서치헬프 — '미결' 라디오 버튼 선택 상태에서 고객 F4 호출 시 미결 잔액이 실제로 남아있는 고객만 팝업에 표시. 반제 선택 시 반제 이력 고객만 조회
  • XBLNR 참조번호 기반 원천문서 점프 — 참조번호 접두어(WO/MM/OD)를 판별해 생산오더·구매검수·영업납품 등 전표를 발생시킨 타 모듈 원천 문서로 다이렉트 드릴다운
  • 마스터 텍스트 일괄 매핑 — 수천 건 루프마다 DB SELECT 대신 고객·사원·공급업체 마스터를 인터널 테이블에 선적재 후 VALUE #( ... OPTIONAL )로 메모리 내 매핑해 조회 성능 확보

핵심 기능 상세
  • ALV Tree 5단 계층 — 전체 → AR/AP → 통화(EUR/JPY/USD) → 거래처 → 전표 드릴다운. 노드 클릭 시 우측 Grid 자동 필터링
  • 통화별 변동률(%) 시뮬레이션 — EUR/JPY/USD 개별 % 입력 → 환율 동적 계산 → 실행 시 Tree·Grid 동시 반영. 최근 1주일 평균 환율 자동 세팅
  • 시뮬레이션 배수 CDS 파라미터화 — 변동률(%)을 CDS View 파라미터(p_usd/p_eur/p_jpy)로 넘겨 SimFactor 계산을 HANA DB단에 위임. ABAP 재계산 루프 제거
  • 평가손익 컬러 표시 — 이익=녹색 / 손실=빨강 셀 컬러. AR·AP 요약 카드로 전체 손익 한눈에 파악
  • 미결잔액 TOP5 차트 — ALV Chart 버튼 클릭 시 거래처별 미결잔액 막대 차트 팝업
  • 외화보유현황 탭 — 은행 보유 외화 + AR/AP 미결 외화 집계. 통화별 시계열 차트 내장
  • 평가/환입전표 팝업 — 생성 전 예정 내역 미리보기. Function Module로 팝업 재사용
  • 배치잡 자동 전표 생성 — 말일 평가전표 + 익월 1일 환입전표 쌍으로 자동 생성. Posting Class ZCL_E3_FI_DOCUMENT 재사용
  • 핫스팟 팝업 연동 — 전표번호 클릭 시 전표 상세 팝업, 거래처 코드 클릭 시 고객/공급업체 마스터 조회. 공용 Function Group(ZFGE3FI01) 재사용
  • 요약 보기 / 전체 보기 전환 — gv_expand='X' 상태에 따라 소계 행 화살표(▶/▼) 아이콘을 전환. 소계 클릭 시 거래처명을 마스터에서 재조회해 동적 표시
  • 전표 상태 아이콘 자동 표시 — 평가손익 부호 기준으로 이익(녹색)·손실(빨강)·동일(비활성화) 신호등 아이콘과 상태 텍스트를 셀에 자동 반영
  • 외화보유현황 12개월 추이 차트 — USD/EUR/JPY 통화별 보유잔액 최근 12개월 시계열 꺾은선 차트. 은행 보유액 + AR/AP 미결 외화 합산 표시

  • Excel 저장 / PDF 출력 — 현재 조회 조건의 상세 내역을 xlsx로 다운로드하거나, 요약 카드+차트+상세 내역을 PDF 보고서로 변환

  • 직급별 기본급 자동 매핑 — 대표·이사·부장·과장·대리·사원 등 직급 선택 시 사전 정의된 기본급을 자동으로 채워 입력 오류 방지

  • 부서별 인건비 대시보드 — 부서별 급여합계를 막대 차트로 시각화하고, 인원·평균급여·전체 대비 비중(%)을 테이블로 함께 제공

  • 급여 이력 Time-Slice 관리 — 급여 변경 시 기존 이력의 종료일(ENDDA)을 신규 시작일-1로 닫고 새 레코드를 INSERT. 이력 삭제 없이 과거 시점 급여도 그대로 추적 가능
